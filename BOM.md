# V3 hardware BOM

Structural interface:
- 4 x M4 Dell VESA screws — length to be measured on the actual AIO
- 4 x M4 fender washers, about 20 mm OD
- 4 x M8 steel carriage bolts / equivalent studs
- 4 x M8 large washers
- 4 x M8 locking nuts / thin jam nuts as required by the actual stud-head stack
- 1 x M5 socket-head screw for anti-lift block
- 1 x M5 square nut for receiver pocket
- optional 2 mm aluminum receiver backer
- optional steel safety tether

Enclosure:
- M3 screws, washers and nyloc nuts for rear seam joiners
- 8 x M3 threaded inserts (or service-selected equivalent) for front retainer tabs
- 8 x M3 front retainer screws

Wall:
- fasteners/anchors selected for the actual wall substrate; CAD hole patterns are only the layout.
